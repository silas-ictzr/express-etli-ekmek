# Express Etli Ekmek Lahmacun

Keçiören Bademlik'teki Express Etli Ekmek Lahmacun'un web sitesi.

- `index.html`: sitenin tamamı (tek sayfa)
- `img/`: açılış ve menü fotoğrafları
- `favicon.svg`: tarayıcı sekmesindeki logo

Menü ve fiyatlar `index.html` içindeki `MENU` listesinden düzenlenir.

> Bu sürüm müşteri önizlemesidir: arama motorlarına kapalıdır (`noindex`). Site asıl alan adına taşınınca `index.html` içindeki `robots` satırı silinmeli.
